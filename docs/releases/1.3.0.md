# Release 1.3.0

Rama `release/1.3.0` creada desde `develop` en `0afe1a5`, después del merge de los PR #29 y #30. Destino del PR: `main`.

## Cambios

- La bolsa Hotfix del selector tiene una flecha en forma de gota de vidrio. Al pulsarla, la bolsa gira y muestra su otro lateral («Good coffee. Better ideas.»); la gota pasa al lado izquierdo para volver al frente. Al cambiar de café vuelve al frente.
- Las presentaciones con stock 0 ya no muestran «Agotado por ahora». Muestran «Nuevo lote en camino» y el botón «Reservar mi café», que abre un formulario (cantidad, celular, nombre, distrito o ciudad y comentario) y arma el mensaje de reserva en WhatsApp. Las reservas no se guardan en la base de datos ni se cobran.
- El modo reserva se activa solo según el stock del panel; al cargar stock el café vuelve a venderse con Culqi.

## Despliegue

No cambia las dependencias, las variables de entorno ni la base de datos (sin migraciones nuevas). Se conserva la configuración documentada en `1.1.0.md`.

Antes de fusionar, esperar los checks de CI. Después del despliegue, comprobar `/api/health` con versión `1.3.0`, la flecha del Hotfix en escritorio y celular, y el formulario de reserva con una presentación en stock 0 (el mensaje debe abrir el WhatsApp de CodeBrew). Crear el tag `v1.3.0` sobre el commit fusionado y sincronizar `main` hacia `develop`.

Para revertir basta con desplegar la imagen anterior; no hay cambios de datos.
